# Weekly Review

直近7日間の記憶を対象に、本人へ提出する週次レビューを作る。cron から
`--deliver discord` で実行され、結果は Discord のホームチャンネルへ届く。

## 手順

1. `hindsight_reflect` を一度だけ呼び、直近7日間について「何が起きたか」
   「未完了のまま残っていること」「以前の記憶と食い違うこと」を統合する。
   query には集約した依頼文を渡す（日本語でよい）。
2. 1 で挙がった各項目について `hindsight_recall` で裏を取る。根拠が取れない
   項目は出さない。記憶に無いことを推測で補わない。
3. 下のテンプレートで報告する。

## 報告テンプレート

```
## 週次レビュー (YYYY-MM-DD 〜 YYYY-MM-DD)

### 未完了・継続中
- <項目>: <現状> — 根拠: <記憶の要点 / 日付>

### 変更
- <項目>: <前 → 後> — 根拠: <記憶の要点 / 日付>

### 矛盾・要確認
- <項目>: <記憶A> と <記憶B> が食い違う — どちらが正しいか確認したい

### 今週の新規
- <項目> — 根拠: <記憶の要点 / 日付>
```

## ルール

- 本人が明示した事実と、文脈から推測しただけの内容を必ず区別して書く。
  推測は推測だと明記する。推測を事実として書かない。
- 根拠のない項目、挨拶や雑談、一時的な連絡事項は載せない。
- 変化が何も無い週は、本文に `[SILENT]` とだけ書いて終了する。他の文字列を
  出力しない。
- 個人情報や秘匿値（トークン、パスワード等）は本文に転記しない。
